# java-racingcar-precourse

## 📍 추가 요구사항


### 입력 제한
- 자동차 이름은 최대 `10`대 까지 입력할 수 있다.

- 게임 진행 횟수는 최대 `30`까지만 입력할 수 있다.

### 규칙 추가
- 게임 진행 횟수로 `0`이 입력될 수 없다.

- 자동차는 최소 한 대 이상 입력되어야 한다.


## 📝 기능 목록 정리


### 입력
- [x] 사용자는 경주할 자동차 이름을 입력할 수 있다.

    - [x] 자동차 이름은 쉼표(`,`)를 기준으로 구분한다.

- [x] 사용자는 게임 진행 횟수를 입력할 수 있다.

    - [x] 숫자 외의 다른 값이 입력되면 `IllegalArgumentException`을 발생시킨다.

    - [x] 진행 횟수로 `0`이 들어오면 `IllegalArgumentException`을 발생시킨다.


### 출력
- [x] 시스템은 정해진 형식에 맞는 차수별 실행 결과를 출력한다.

    - [x] 형식 : (ex. [자동차 이름] : ---)

    - [x] 출력 시 자동차 이름을 함께 출력한다.

    - [x] 자동차의 전진 횟수 만큼 '-'를 출력한다.

- [x] 시스템은 정해진 형식에 맞는 우승자 안내 문구를 출력한다.

    - [x] 형식 : (ex. 최종 우승자 : [자동차 이름])

    - [x] 우승자가 여러 명일 경우 쉼표(`,`)를 이용하여 구분한다.


### 도메인 규칙/검증
- [x] 자동차 이름은 5자 이하만 가능하다.

    - [x] 입력한 자동차 이름이 5자 초과일 때 `IllegalArgumentException`을 발생시킨다.

- [x] 자동차는 최소 한 대 이상 입력되어야 한다.

    - [x] 공백이나 띄어쓰기 입력 시 `IllegalArgumentException`을 발생시킨다.


### 게임 진행
- [x] 0에서 9 사이의 무작위 값을 구한다.

- [x] 구한 무작위 값이 4 이상일 경우 해당 자동차는 전진한다.

- [x] n번의 진행 이후 전진 회수를 집계한다.

- [x] 집계 결과에 따라 최종 우승자를 뽑는다.
